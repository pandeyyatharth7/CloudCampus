# CloudCampus frontend

React 19 + TypeScript + Vite SPA for CloudCampus. No AWS SDK and no Amplify:
Cognito is used directly against the hosted UI endpoints with PKCE.

## Run it

```powershell
# from the repository root
Copy-Item frontend/.env.production frontend/.env.local   # points at the demo backend
npm --prefix frontend install
npm --prefix frontend run dev                            # http://localhost:5173
```

The Cognito app client already registers `http://localhost:5173/` as a callback,
so hosted-UI sign-in works from the dev server. To target your own stack, update
`frontend/.env.local` with the values from your `deployment-outputs.json` (see
the root [`README.md`](../README.md#configuration) and
[`docs/deployment.md`](../docs/deployment.md)).

## Scripts

```powershell
npm ci           # clean install from the lockfile
npm run dev      # Vite dev server on http://localhost:5173
npm run build    # tsc -b && vite build -> dist/
npm run lint     # oxlint
npm run preview  # serve the production build locally
```

## Configuration

Environment variables are read from `.env.production` (generated by
`scripts/deploy.ps1`) or `.env.local` for local development. See
[`.env.example`](.env.example) for the full list. All values are public
identifiers — there are no secrets, and no AWS credential ever reaches the
browser. `.env.production` is committed on purpose so a fresh clone can talk to
the deployed backend without any setup.

| Variable | Meaning |
|---|---|
| `VITE_API_URL` | API Gateway base URL (no trailing slash) |
| `VITE_COGNITO_REGION` | Region hosting the Cognito user pool |
| `VITE_COGNITO_USER_POOL_ID` | Cognito user pool id |
| `VITE_COGNITO_CLIENT_ID` | Cognito app client id (public in a PKCE SPA) |
| `VITE_COGNITO_DOMAIN` | Cognito hosted-UI domain (no `https://`) |

## Source layout

| File | Responsibility |
|---|---|
| `src/main.tsx` | React entry point |
| `src/App.tsx` | App shell: view state, sign-out |
| `src/app-shell.tsx` | `useApi()` (bearer token, refresh, 401 retry), header |
| `src/auth.ts` | Cognito hosted UI + PKCE, code exchange, refresh, logout |
| `src/views-events.tsx` | Discover list (search / category / empty / full) and event detail |
| `src/views-manage.tsx` | My registrations and the organizer dashboard |
| `src/app.css`, `src/auth.css`, `src/index.css` | Styles |
